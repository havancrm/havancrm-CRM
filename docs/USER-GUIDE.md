# คู่มือใช้งาน HAVAN CRM สำหรับเซลล์ภาคสนาม

เปิดบนมือถือ (เบราว์เซอร์) แล้ว "เพิ่มไปที่หน้าจอโฮม" ได้ ใช้ได้แม้สัญญาณหลุด — งานที่บันทึกจะรอส่งแล้วซิงก์เองเมื่อมีสัญญาณ (ดูสถานะที่ปุ่มมุมขวาบน: ซิงก์แล้ว / รอส่ง / ออฟไลน์)

## เมนูล่าง 5 ปุ่ม
หน้าแรก · ลูกค้า · เข้าพบ · ออเดอร์ · ตั้งค่า (ปุ่มย้อนกลับมุมซ้ายบนกลับหน้าเดิม ข้อมูลที่กรอกไม่หาย)

## หน้าแรก
- ช่องค้นหา: พิมพ์ชื่อร้าน รหัสลูกค้า เบอร์โทร ป้ายกำกับ ชื่อสินค้า หรือเลขบิล
- การ์ด 4 ช่อง: ลูกค้าทั้งหมด / ปัจจุบัน / ห่างหาย / เลิกกิจการ — แตะเพื่อดูรายชื่อ
- ทางลัด: รายงานยอดขาย, ลูกค้าใหม่, รอบลูกค้า, รับออเดอร์, แผนที่, ปฏิทินเข้าพบ
- ป้ายกำกับ (2 คอลัมน์): แตะเพื่อดูร้านที่มีป้ายนั้น

## ลูกค้า และหน้าลูกค้า (Customer 360)
- แท็บ: ภาพรวม · ข้อมูล · ประวัติซื้อ · เข้าพบ
- ปุ่มด่วน 5 ปุ่ม: **บันทึก | รูป+พิกัด | รับออเดอร์ | โทร | นำทาง** (โทร/นำทางจะบันทึกเป็นกิจกรรมให้)
- ภาพรวมเห็น: บิลล่าสุด, สินค้าที่สั่งประจำ, บันทึกก่อนเข้าร้าน, วันเกิด, รูปหน้าร้าน, สถานะพิกัด, รอบซื้อ
- แก้ข้อมูลลูกค้า: แท็บ "ข้อมูล" → แก้ไข (เบอร์ ป้ายกำกับ โน้ต ฯลฯ ระบบเขียนเฉพาะช่องที่เปลี่ยน)

### เพิ่มร้านใหม่ระหว่างเข้าพบ
หน้า ลูกค้า → **เพิ่มร้านใหม่** → ใส่ชื่อร้าน (บังคับ) เบอร์ ที่อยู่ ฯลฯ กด "ใช้ตำแหน่งนี้" ถ้าอยู่หน้าร้าน
- ถ้าชื่อหรือเบอร์ซ้ำกับร้านที่มี ระบบเตือน — ถ้าเป็นคนละร้านจริงให้ติ๊ก "ยืนยันว่าเป็นคนละร้าน"
- ร้านใหม่ได้ **รหัสชั่วคราว `N-…`** และป้าย "ยังไม่มีรหัสบัญชี" ยังรับออเดอร์ได้ (ใบส่งสินค้าจะพิมพ์ "รอรหัสบัญชี")
- เมื่อสำนักงานมีรหัสบัญชีแล้ว **ผู้ดูแล** กด "ผูกรหัสบัญชี" ในแท็บข้อมูล หรือนำเข้ารายงานลูกค้า TTX (ระบบจับคู่ร้านที่ชื่อ/เบอร์ตรงให้)

## บันทึกเข้าพบ / โน้ต / นัดหมาย (ฟอร์มเดียว)
ปุ่ม **บันทึก** → เลือก
- **เข้าพบ**: ผลการเข้าพบ, แนบพิกัด GPS (แสดงระยะห่างจากพิกัดร้าน), ถ่ายรูปได้แต่ไม่บังคับ
- **โน้ต**: บันทึกข้อความ
- **นัดหมาย**: เลือกวัน → สร้างงาน "ติดตาม" ขึ้นปฏิทิน; ทำเสร็จแล้วกด "เสร็จแล้ว" ในแท็บเข้าพบ
**รูป+พิกัด**: อัปเดตพิกัดร้าน (ถ้าห่างจากเดิมเกิน 300 ม. จะถามยืนยัน) และถ่ายรูปหน้าร้าน

## เข้าพบ (รอบลูกค้า + ปฏิทิน)
- **รอบลูกค้า**: เลยรอบซื้อ / ใกล้ถึงรอบซื้อ / ขาดเข้าพบ (คำนวณจากประวัติซื้อจริง)
- **ปฏิทิน**: สลับ "แสดงแบบเดือน" (การ์ด 12 เดือนต่อปี เลือกปี แตะเดือนเพื่อดูรายชื่อ) หรือ "แสดงแบบวัน" (ตารางวันที่ ตัวเลข = จำนวนร้าน แตะวันดูรายชื่อ)

## ออเดอร์
1. ออเดอร์ → **ออเดอร์ใหม่** (หรือปุ่ม "รับออเดอร์" ในหน้าลูกค้า) → เลือกร้าน
2. เลือกสินค้าจาก 4 แหล่ง: **บิลล่าสุด / บิลย้อนหลัง / สั่งประจำ / ทั้งหมด** (แตะ + เพิ่ม; "เพิ่มทั้งบิล" ได้)
3. แถบ "ตะกร้า" ด้านล่าง → แก้จำนวน/ราคา ลบรายการ ใส่เงื่อนไขชำระ/หมายเหตุ
4. **บันทึกร่าง** (สถานะ ร่าง) หรือ **ยืนยันออเดอร์** (สถานะ รอส่ง) → แสดง **ใบส่งสินค้าชั่วคราว** บนแบบฟอร์ม Havan: คัดลอก / พิมพ์-PDF / แชร์
- ตะกร้าไม่หายเมื่อกดย้อนกลับหรือปิดแอป
- รหัสสินค้าที่ไม่อยู่ในทะเบียนปัจจุบันจะไม่ถูกเดา ให้เลือกสินค้าทดแทนจากแท็บ "ทั้งหมด"
- เมื่อบิลจริงถูกนำเข้า ออเดอร์ที่ลูกค้า+ยอดตรงกันจะถูกเชื่อมเป็น "ส่งแล้ว" อัตโนมัติ

## รายงานยอดขาย / ลูกค้าใหม่ / แผนที่
- ยอดขาย = ผลรวมรายการสินค้าในบิล (ไม่บวก VAT ซ้ำ) เลือกช่วงเวลา; ดูตามเดือน/เสมียน-พนักงานขาย/ลูกค้า/บิล แตะบิลเพื่อดูรายการ
- ลูกค้าใหม่: แยก "ซื้อครั้งแรก" กับ "เพิ่มทะเบียน"
- แผนที่: กด "ใกล้ฉัน" เรียงร้านที่มีพิกัดตามระยะ, "นำทาง" เปิด Google Maps

## ตั้งค่า (ผู้ดูแลเห็นครบ)
เกณฑ์รอบซื้อ/ห่างหาย · ป้ายกำกับ · นำเข้า TTX (บิล หรือ รายงานลูกค้า) · ตรวจคุณภาพข้อมูล · ประวัติการนำเข้า · รหัส/ชื่อสินค้าที่ไม่ตรงทะเบียน (ส่งออก CSV) · ซิงก์และบัญชี (ซิงก์ตอนนี้, งานค้าง, ตรวจโครงสร้าง 18 แท็บ, ล้างแคช, ออกจากระบบ)
สิทธิ์: ต้องมีอีเมลในแท็บ `ACCESS` ของชีต (active = TRUE) ; `role = admin` จึงแก้เกณฑ์/ป้ายกำกับ/นำเข้า TTX/ผูกรหัสได้

## ถ้าเกิดปัญหา
- ขึ้น "ไม่มีสิทธิ์ใช้งาน": เพิ่มอีเมลนั้นในแท็บ ACCESS (active = TRUE)
- ปุ่มมุมขวาบนขึ้น "ค้าง N": งานนั้นถูกเซิร์ฟเวอร์ปฏิเสธ → ตั้งค่า → ซิงก์และบัญชี ดูสาเหตุ แล้วส่งอีกครั้งหรือทิ้ง
- หน้าไม่อัปเดต: ตั้งค่า → ซิงก์และบัญชี → ซิงก์ตอนนี้ / ล้างแคช (งานที่รอส่งไม่หาย)
